# Underground City

A private-play Minecraft living-world RPG project about rival cities, civilian careers, crime, trade, faction warfare, and an evolving story. Built for a small co-op group with meaningful NPC-driven gameplay.

**Status:** Pre-production. The mod loader, version, dependencies, maps, and gameplay architecture are candidates until proven in a dedicated-server test.
