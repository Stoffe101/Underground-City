# Furnished cities: original buildings by city (D-117, D-118, D-119)

Status: **implemented as an opt-in generation package; ten buildings generated, probed block by block in disposable worlds and photographed from outside and inside in a real client; nobody has walked through one.** This document says what exists, how it is made and checked, what a photograph of it showed, and what is not true yet.

## What the owner found

The first playtest: the three cities looked alike (one generic Lost Cities set), their buildings were empty shells, and there was nothing to do inside them. The brief of October 21 asked for distinct, furnished, believable buildings and a lived-in residential neighbourhood and commercial block, built without publishing anyone's protected assets.

## How it is made

* **Original, from code.** `scripts/citykit.py` (a small kit: palettes, six-slice parts, furniture helpers, stairs, mirrored plans) and `scripts/city_valewood.py`, `city_ironhaven.py`, `city_blackwater.py`, `city_blocks.py` write original Lost Cities buildings: parts, palettes, building definitions, `stuff` overrides and a city style per city. Nothing in the repository is third-party content; Modern Life furniture is named by block id and exists only at run time in a pack that has it (the pinned `modern_life` mod, set `furnished`, runtime-only, all rights reserved, never committed).
* **Packaged as its own low-code mod** `underground_city_furnished` (`content/generated/world-furnished/`, 73 generated files, regenerated by `python scripts/emit_dev_world_pack.py --layout furnished`, checked for currency in CI). It is opt-in (`-PucPack=world,furnished`) and requires the archipelago layout.
* **Which building where** is data, not code: `data/underground_city/city_character/<city>.json` gives, for a city, rings by fraction of the city's radius with weighted building ids, and the city's style. `CityCharacter` applies it on Lost Cities' own `CharacteristicsEvent` (its public API, reached by reflection so the build does not depend on it): every city chunk gets the city's style; a building chunk gets a building chosen by a hash of the world seed and the chunk, so the same world always gets the same city; multi-building lots are converted to single lots unless the city keeps them.
* **What a building also carries.** A security class and a rule with a priority that outranks the stock fallback (`building_security/furnished.json`, with the alarm profiles of [police response](police-response.md)); a sidecar of spots (door, bed, stove, seat, counter, desk, bench, anvil, shelf, stash, in the building's own coordinates) that [households](households.md) read; notes.

## How it is checked (D-119)

1. **Every block is checked against the real game.** `scripts/validate_city_blocks.py` compares each block named in a palette with the registry dump a real game produced (`CityProbe` with `--registry`): a name that does not exist fails. This found a wrong block name (`night_stand`) that had silently emptied a whole building's chunk.
2. **Every building is generated and compared with its plan.** `scripts/run_city_probe.py` starts a disposable dedicated server, forces chunks, and writes chunk text dumps; `scripts/city_dump_diff.py` compares each dumped chunk with the plan floor by floor; `scripts/check_city_probe.py` judges the whole probe. Result of the 675-chunk run: **0 Lost Cities errors**, every building generated faithfully; one building (`vw_house_b` at one chunk) was covered below the judge's threshold and is named in the report, not hidden.
3. **Packages are regenerated and compared in CI** (`tests/test_dev_client.py`).
4. **A generation-pack guard.** The furnished and scarcity packages change how *new chunks* generate; they never rewrite chunks that exist. `GenerationPackGuard` writes `uc_generation_packs.json` into a new world and refuses to start an existing world with a different set of these packages, so a player's world cannot be silently altered by installing one. (D-118; GameTested, including the refusal.)

Defects the checks found and fixed during this work, in the order found: Lost Cities gave a predefined city's style only to the centre chunk (hence the character hook); a block name that did not exist; camelCase keys (`allowDoors`) that were ignored when written snake_case, so doorways opened at fence gaps; Lost Cities' own `stuff` decorations (cobwebs, chains) in buildings, removed by an override whose first form crashed every chunk (`maxcount 0`); crops that vanish at generation (replaced by soil, pumpkins, melons and hay); a ceiling lamp that was not powered, so interiors were dark.

## What a photograph showed

October 21, in a real client (a software renderer, 1920 by 1080, a disposable world, spectator camera, daylight):

* **Valewood, from the street:** two-storey houses in pink render with a timber frame, red or dark roofs with chimneys, front doors with steps and flagged paths, fenced gardens with hedges and flowers, a shop with a red-and-white awning and a window display, a pond. It reads as a small town, not as Lost Cities' default set. A garden's planting rows are one-block trenches in the grass rather than crops; a flaw.
* **Through the window:** the kitchen of a house, a table with chairs, a cooker, in a lit room.
* More frames (interiors of each building, a night frame, Ironhaven and Blackwater) are listed in the sprint report with what each showed; whatever the report does not name was not looked at.

## What is not true yet

* Nobody has walked through a furnished building or sat in a chair. There is no police response *to* furnished buildings beyond the class alarm profiles, and the shops sell nothing (the counters are furniture).
* The buildings are small, few, and repeat: ten types for three cities. Every building of a type is identical (mirrored for variety); no building has an individual history.
* The commercial block is one ring of Blackwater with three building types. There are no streets of shops, no market, no signage beyond the shop awning.
* No daylight and artificial light audit beyond the photographs; no sound; no decoration of the streets themselves.
* The package is opt-in and not part of the default pack; it has not been in a CI journey.
* Lost Cities' building count per city, the building mix and the relation of the three cities' radii have not been tuned.
